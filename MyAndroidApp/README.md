# MyAndroidApp

This is a new Android project created using Android Studio's 'Empty Activity' template.

**Language**: Kotlin
**Target API Level**: 34
**Package Name**: `com.example.myandroidapp`

## Project Structure

The project follows a standard Android application structure. Key directories and files include:

- `app/`: Contains the source code, resources, and build files for the main application module.
- `gradle/`: Contains Gradle wrapper files.
- `build.gradle.kts` (Project-level): Global build configuration.
- `app/build.gradle.kts` (Module-level): Module-specific build configuration.
- `settings.gradle.kts`: Defines project modules.
- `AndroidManifest.xml`: Declares application components and permissions.
- `MainActivity.kt`: The main activity for the application.
- `res/`: Contains application resources like layouts, drawables, and values (strings, colors, themes).

## Getting Started

To run this project, open it in Android Studio. The IDE will handle dependency synchronization and allow you to run the application on an emulator or a physical device.
